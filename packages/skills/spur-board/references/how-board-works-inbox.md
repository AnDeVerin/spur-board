# Operator inbox items

Kinds of [operator inbox](how-board-works-blocks.md#operator-inbox) entries: what to do, when each clears.

## Item kinds

<!-- prettier-ignore-start -->
| Kind | Condition | Action | Severity | Clears when | URL |
| --- | --- | --- | --- | --- | --- |
| `token_request` | an agent asks for a token | approve or deny it in Slack within 15 minutes of asking | attention | approved, denied, expired or revoked | stored target |
| `post_blocked` | a text looked like a secret and was not sent | read it, then close the item | attention | its block closes or you close the item | stored target |
| `post_failed` | a chat delivery failed | check the chat gateway, then retry the item | failure | you retry or close the item | own delivered message permalink, else the immediate parent's when known |
| `transport_health` | a chat connection is down | check the Slack app tokens | failure | the connection is back | stored target |
| `answer_undelivered` | an answer did not reach the asking session | check the asking session, then retry the item | failure | you retry the item, the session reads it or its block or turn closes | stored target |
| `worker_not_reading` | the worker does not read its doorbell | check the worker session, then retry the item | failure | you retry the item, the worker reads it or its block or turn closes | stored target |
| `answer_author_unavailable` | no live session can take an answer | with a task: comment on it so a live session reads the answer; without: pass it to the asking session yourself; then close the item | attention | you close the item | stored target |
| `inbound_failure` | a chat message could not be applied | check the daemon log, then retry the item | failure | a retry applies it or you close the item | stored target |
| `inbound_gap` | chat messages may be missing | check the conversation for missed messages | failure | you close the item | stored target |
| `board_observation` | any other key | check the task, then close the item | attention | the condition ends or you close the item | stored target |
| `board_observation` `source:` | a source is blind | check the token, settings, daemon or source it names | failure | the source reads again | official GitHub REST troubleshooting or Jira REST docs; absent for Spur or unknown sources |
| `board_observation` `default-branch:` | the latest check run of a push-triggered workflow on a linked repo's default-branch head failed, was cancelled or timed out, or a commit status there failed; other runs (scheduled, manual) and non-workflow check runs never count, and branch protection is not read. The text names the repo, first red commit, check and run; each red re-read moves its fact time, not the text; `status.get` shows `sources[].defaultBranch` | open the failing run; fix or revert | failure | a later default-branch head is green | stored failing run or status target, retained after handling |
| `board_observation` `pr-outcome:` | a linked PR closed unmerged or vanished | check the PR, then close the item or archive the task | attention | the PR is seen again or you close the item; unlinking does not clear it | stored target |
| `board_observation` `lookup:` | the ticket lookup failed | check the tracker ticket, then close the item or archive the task | attention | a lookup succeeds or you close the item | stored target |
| `board_observation` `operator-block:` | a block waits for you | not listed: shown as its block | attention | the block closes, also via Close on its feed line | stored target |
| `board_observation` `block:` | a block waits for its addressee | answer `B<n>` if it is a question, or close it with a reason; listed only when the block is not addressed to you; otherwise shown as its block | attention | the block closes | stored target |
| `board_observation` `filter:` | the ticket left the tracker filter but work is live | return the ticket to the filter, or finish or unlink the linked work (`board unlink <task> --pr <pr> --reason <reason>`) | attention | the ticket is back in the filter or no linked open PR or live session is left | stored target |
| `board_observation` `health:` | a session health flag | check session `<session>` in Spur; a vanished worker: start a new one or archive the task | attention | the flag ends; for a vanished worker also when the ticket is done | stored target |
| `board_observation` `no-session:` | a named-orchestrator column's untaken turns have no live session to ring for its `noRecipientAfterMs` (default 10 min), timed from the later of the ring and the first end, absence or finished state (stopped, killed, errored, completed) of the last recipient session of the column's Spur project or the task's linked orchestrator; one item per project and column, on the oldest waiting turn's task, with the waiting count and minutes without a live session; doctor check `orchestrator.sessions` also warns `no live session` | start a session in Spur project `<spur>`, or take over its turns with an inbox ack | attention | a live session appears or the turns are taken or closed; a later full-length gap raises it again; once closed, it stays closed while the same oldest turn waits | stored target |
| `board_observation` `review-rule:` | under `approvalRule: github-rules`, a task in External Review whose head has no stored decision and GitHub left undecided (merge state unknown or behind, or a rule the token cannot read) for 30 minutes, time outside External Review included, so a same-head return can raise it at once; one item per task, PR and undecided stretch of a head, naming the current cause with the raw `mergeStateStatus`, `mergeable` and `reviewDecision` of its first raise; once closed, it stays closed while its text is the same. A draft, a conflict, changes requested (GitHub's too, at any merge state) and a pending or missing required check have their own reasons and end the stretch | check the PR on GitHub: update the branch, let the token read the base branch rules or wait, then close the item | attention | GitHub decides the head, the state gets its own reason, a new head arrives or the task leaves | stored target |
| `board_observation` `external-quiet:` | a task with an open PR sat in External Review past its `quietAfterMs` with no new external review round; held while GitHub is blind or stale | request a new external review round or approve the PR by hand | attention | a new external review or head, or the task leaves | stored target |
| `worker_ended` | an agent holding the current open non-Done turn ended for any reason, PRs or links aside; also a killed worker without a PR whose ticket is not done; a new item posts a feed line with Close; each complete Spur poll moves its fact time | start a new worker or archive the task; an operator turn: retake it (`board inbox ack`) | attention | the turn closes, its holder changes, the task leaves the column visit or is archived; a turnless worker: the health flag ends or the ticket is done | stored target |
| `turn` | a turn is yours | listed as its `T…` entry | attention | the turn closes | absent |
| `anomaly` | a live session or turn of the task is stuck, or a worker completed without a [counting PR](how-board-works-done.md#merged-pr-alerts), its ticket not done, and has no current open turn | wait for the answer to `B<n>`, or answer it yourself; listed only when addressed to the curator; otherwise shown as its block | attention | the condition ends (a done ticket ends it even while Spur is blind) or its block closes | stored target |
| `cycle_limit` | the task reached its column's cycle limit | not listed: shown as its block | attention | its block closes | stored target |
| `course_check` | the task keeps returning from a column | wait for the answer to `B<n>`, or answer it yourself; listed only when addressed to the curator or orchestrator; otherwise shown as its block | attention | its block closes | stored target |
| `conversation_waiting` | your conversation waits for a live session | start a session in its Spur project, or close `B<n>` with a reason | attention | a session starts or the block closes | stored target |
<!-- prettier-ignore-end -->
